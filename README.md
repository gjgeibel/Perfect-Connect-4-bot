## Opening Book
In order to run the solver and game this project requires the `7x6.book` opening book from Pascal Pons'Connect Four solver.
Download `7x6.book` here:

https://github.com/PascalPons/connect4/releases/download/book/7x6.book

After downloading, place `7x6.book` in the same folder as the Python files and then run the game.
